# 眠れない夜チャレンジとは？

「眠れない夜チャレンジ」は、櫻坂46の16thシングル表題曲『愛MUST BE』を用いたTikTok上のダンスチャレンジです。

楽曲の歌詞に「眠れない夜があっても 君だけじゃないんだよ」というフレーズがあることに由来し、主に曲中の2番Aメロ部分の振り付けを踊るショート動画を投稿する形式で広がっています。参加者はハッシュタグ「#眠れない夜チャレンジ」および「#櫻坂46_愛MUSTBE」を付けてTikTokなどに動画を公開します。

## 経緯

2026年10月頃、ファン（Buddies）の高校生らが楽曲をより多くの人に広める目的で投稿を開始したことがきっかけです。以降、ファン間で急速に拡散し、盛り上がりを見せています。メンバーの石森璃花さんも公式Instagramで参加動画を投稿するなど、グループ側からも反応が確認されています。

これは公式に企画されたものではなく、ファン発の草の根的なムーブメントです。楽曲の世界観や「愛が愛を生む」というテーマへの共感を背景に、グループの認知拡大を目指す取り組みとして機能しています。
